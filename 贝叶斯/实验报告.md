### 2. 算法原理

#### 贝叶斯定理

贝叶斯定理是朴素贝叶斯分类器的理论基础，其公式为：

$$P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}$$

其中：
- P(A|B)：后验概率（在B发生的条件下A发生的概率）
- P(B|A)：似然概率（在A发生的条件下B发生的概率）
- P(A)：先验概率（A发生的概率）
- P(B)：证据概率（B发生的概率）

#### 朴素贝叶斯分类器

朴素贝叶斯分类器基于**特征条件独立假设**：假设各个特征之间相互独立。对于给定的样本 X = (x1, x2, ..., xn)，其属于类别 Ck 的概率为：

P(Ck|X) = P(X|Ck) * P(Ck) / P(X)

由于 P(X) 对于所有类别都是相同的，在分类时只需比较分子部分：

P(Ck|X) ∝ P(Ck) * Π[P(xi|Ck)] (i=1到n)

#### 多项式朴素贝叶斯

多项式朴素贝叶斯适用于离散特征（如词频）的分类任务，其条件概率计算如下：

P(xi|Ck) = (Nki + α) / (Nk + α * V)

其中：
- Nki：类别 Ck 中特征 xi 出现的次数
- Nk：类别 Ck 的样本总数
- α：平滑参数（通常取1，即拉普拉斯平滑）
- V：特征词汇表大小

### 3. 关键代码展示

#### 数据预处理代码

```python
import re
import string

def preprocess(text):
    text = text.lower()
    text = re.sub(r'[{}]'.format(string.punctuation), '', text)
    text = re.sub(r'\d+', '', text)
    text = text.strip()
    return text

def load_data(file_path):
    X = []
    y = []
    with open(file_path, 'r', encoding='utf-8') as f:
        for line in f:
            parts = line.strip().split('\t')
            if len(parts) >= 2 and parts[1].strip():
                label = parts[0]
                text = '\t'.join(parts[1:])
                X.append(preprocess(text))
                y.append(label)
    return X, y
```

#### 主程序流程

```python
from sklearn.model_selection import train_test_split
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.metrics import confusion_matrix, classification_report

X, y = load_data('data/spam_train.txt')

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42
)

vectorizer = CountVectorizer()
X_train_vec = vectorizer.fit_transform(X_train)
X_test_vec = vectorizer.transform(X_test)

clf = MultinomialNB(alpha=1.0)
clf.fit(X_train_vec, y_train)

y_pred = clf.predict(X_test_vec)
```

### 6. 类别不平衡分析

**垃圾短信(正例)召回率：** 0.8750

**召回率偏低的影响分析：**
- 垃圾短信召回率为87.5%，意味着有12.5%的垃圾短信被漏检（FN=15）
- 在实际应用中，漏检的垃圾短信会进入用户收件箱
- 可能导致用户收到骚扰信息、诈骗信息，影响用户体验和信息安全

**改进建议：**
1. **调整决策阈值**：降低分类阈值，提高垃圾短信的识别率
2. **数据增强**：增加垃圾短信样本数量
3. **特征工程**：使用更有效的特征（如 TF-IDF）
4. **集成方法**：结合多个分类器提高召回率
