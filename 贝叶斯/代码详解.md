### 3.1 数据预处理模块 (`preprocessing.py`)

#### 3.1.1 `preprocess()` 函数

```python
import re
import string

def preprocess(text):
    text = text.lower()
    text = re.sub(r'[{}]'.format(string.punctuation), '', text)
    text = re.sub(r'\d+', '', text)
    text = text.strip()
    return text
```

**功能说明：**

| 步骤 | 操作 | 代码 | 目的 |
|------|------|------|------|
| 1 | 小写化 | `text.lower()` | 消除大小写差异，例如 "Hello" 和 "hello" 视为相同 |
| 2 | 去除标点 | `re.sub(r'[{}]'.format(string.punctuation), '', text)` | 移除标点符号，减少噪音 |
| 3 | 去除数字 | `re.sub(r'\d+', '', text)` | 移除数字，垃圾短信常包含数字但对分类影响较小 |
| 4 | 去除首尾空格 | `text.strip()` | 清理文本格式 |

**输入输出示例：**
```python
# 输入
preprocess("URGENT! Call 09061701461 to claim your prize!")

# 输出
"urgent call to claim your prize"
```

#### 3.1.2 `load_data()` 函数

```python
def load_data(file_path):
    X = []
    y = []
    with open(file_path, 'r', encoding='utf-8') as f:
        for line in f:
            parts = line.strip().split('\t')
            if len(parts) >= 2 and parts[1].strip():
                label = parts[0]
                text = '\t'.join(parts[1:])
                X.append(preprocess(text))
                y.append(label)
    return X, y
```

**功能说明：**

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 打开文件 | 使用 `utf-8` 编码读取 |
| 2 | 逐行解析 | 按制表符 `\t` 分割标签和文本 |
| 3 | 有效性检查 | `len(parts) >= 2` 确保有标签和文本，`parts[1].strip()` 确保文本非空 |
| 4 | 预处理文本 | 调用 `preprocess()` 清洗文本 |
| 5 | 返回结果 | 返回特征列表 `X` 和标签列表 `y` |

**数据集格式：**
```
ham	Go until jurong point, crazy.. Available only in bugis n great world la e buffet...
spam	Free entry in 2 a wkly comp to win FA Cup final tkts 21st May 2005.
```

#### 3.2.3 分层抽样划分数据集

```python

```

**参数说明：**

| 参数 | 值 | 说明 |
|------|-----|------|
| `X` | 特征数据 | 短信文本列表 |

**分层抽样的重要性：**

- 提高模型评估的可靠性

#### 3.2.4 词袋模型特征提取

```python
vectorizer = CountVectorizer()
X_train_vec = vectorizer.fit_transform(X_train)
X_test_vec = vectorizer.transform(X_test)
```

**CountVectorizer 工作原理：**

1. **构建词汇表**：`fit_transform()` 首先扫描所有训练文本，构建词汇表
2. **文本向量化**：将每条文本转换为词频向量
3. **稀疏矩阵**：返回稀疏矩阵以节省内存

**示例：**
```python
# 假设词汇表: {'free': 0, 'win': 1, 'prize': 2, 'call': 3}
# 文本: "free win prize"
# 向量: [1, 1, 1, 0]
```

**输出维度：**
- `X_train_vec.shape` → `(76, 356)`：76 个训练样本，356 个特征（词汇）
- `X_test_vec.shape` → `(20, 356)`：20 个测试样本，356 个特征

#### 3.2.5 多项式朴素贝叶斯分类器

```python
clf = MultinomialNB(alpha=1.0)
clf.fit(X_train_vec, y_train)
```

**MultinomialNB 原理：**

多项式朴素贝叶斯适用于离散特征（如词频）的分类任务，其核心公式为：

$$P(x_i|C_k) = \frac{N_{ki} + \alpha}{N_k + \alpha \cdot V}$$

| 参数 | 含义 |
|------|------|
| $N_{ki}$ | 类别 $C_k$ 中词 $x_i$ 出现的次数 |
| $N_k$ | 类别 $C_k$ 中所有词的总数 |
| $\alpha$ | 拉普拉斯平滑参数（默认 1.0） |
| $V$ | 词汇表大小 |

**拉普拉斯平滑的作用：**
- 解决零概率问题：当某个词在训练集中未出现时，避免概率为零
- $\alpha=1$ 为拉普拉斯平滑，$\alpha<1$ 为 Lidstone 平滑

#### 3.2.6 模型预测与评估

```python
y_pred = clf.predict(X_test_vec)
accuracy = (y_pred == y_test).mean()
```

**预测流程：**
1. 将测试文本转换为词频向量（使用训练时构建的词汇表）
2. 计算每个样本属于 `ham` 和 `spam` 的概率
3. 选择概率最大的类别作为预测结果

#### 3.2.7 混淆矩阵

```python
cm = confusion_matrix(y_test, y_pred)
print("           预测标签")
print("           ham   spam")
print(f"真实标签 ham  [{cm[0][0]:4d}  {cm[0][1]:4d}]")
print(f"        spam [{cm[1][0]:4d}  {cm[1][1]:4d}]")
```

**混淆矩阵解读：**

| | 预测 ham | 预测 spam |
|---|----------|-----------|
| **真实 ham** | TN (True Negative) | FP (False Positive) |
| **真实 spam** | FN (False Negative) | TP (True Positive) |

**术语解释：**
- **TN**：真实为正常短信，预测为正常短信（正确拒绝）
- **FP**：真实为正常短信，预测为垃圾短信（误报）
- **FN**：真实为垃圾短信，预测为正常短信（漏报）
- **TP**：真实为垃圾短信，预测为垃圾短信（正确检测）

#### 3.2.8 分类报告

```python
print(classification_report(y_test, y_pred, target_names=['ham', 'spam']))
```

**分类报告输出：**

```
              precision    recall  f1-score   support

         ham       1.00      0.93      0.97        15
        spam       0.83      1.00      0.91         5

    accuracy                           0.95        20
   macro avg       0.92      0.97      0.94        20
weighted avg       0.96      0.95      0.95        20
```

**指标解释：**

| 指标 | 公式 | 含义 |
|------|------|------|
| **Precision** | $TP / (TP + FP)$ | 预测为正例的样本中真正为正例的比例 |
| **Recall** | $TP / (TP + FN)$ | 真正的正例样本中被正确预测的比例 |
| **F1-score** | $2 \times Precision \times Recall / (Precision + Recall)$ | Precision 和 Recall 的调和平均 |
| **Support** | - | 该类别的样本数量 |

#### 3.2.9 类别不平衡分析

```python
report = classification_report(y_test, y_pred, target_names=['ham', 'spam'], output_dict=True)
spam_recall = report['spam']['recall']
print(f"垃圾短信(正例)召回率: {spam_recall:.4f}")
if spam_recall < 0.9:
    print(f"警告: 垃圾短信召回率偏低({spam_recall:.4f}), 在实际应用中可能导致漏检垃圾邮件，")
    print("      可能带来用户体验下降、信息安全风险等问题。")
else:
    print("垃圾短信召回率较高，漏检风险较低。")
```

**召回率的重要性：**
- **垃圾短信召回率**：所有垃圾短信中被正确识别的比例
- 召回率偏低意味着有垃圾短信漏检到用户收件箱
- 在实际应用中，漏检垃圾短信会影响用户体验和信息安全

## 四、算法原理深入解析

### 4.1 贝叶斯定理

朴素贝叶斯分类器基于贝叶斯定理：

$$P(C_k|X) = \frac{P(X|C_k) \cdot P(C_k)}{P(X)}$$

### 4.2 朴素贝叶斯假设

朴素贝叶斯假设特征之间相互独立：

$$P(X|C_k) = \prod_{i=1}^{n} P(x_i|C_k)$$

### 4.3 分类决策

由于 $P(X)$ 对所有类别相同，只需比较：

$$P(C_k|X) \propto P(C_k) \cdot \prod_{i=1}^{n} P(x_i|C_k)$$

选择使上式最大的类别 $C_k$。
