## 一、实验原理

### 1.1 卷积神经网络（CNN）

卷积神经网络是一种专门用于处理具有网格结构数据（如图像）的深度学习模型。其核心组件包括：

- **卷积层（Convolutional Layer）**：通过卷积核在输入图像上滑动，提取局部特征（如边缘、纹理等）。每个卷积核学习一种特定的特征模式。
- **批归一化层（Batch Normalization）**：对每批数据进行归一化处理，加速训练收敛，提高模型稳定性。
- **激活函数（ReLU）**：引入非线性变换，使网络能够学习复杂的非线性映射关系。
- **池化层（Pooling Layer）**：通过下采样减少特征图的空间维度，降低计算量，同时增强模型的平移不变性。
- **Dropout**：在训练过程中随机丢弃部分神经元，防止模型过拟合。
- **全连接层（Fully Connected Layer）**：将提取的特征映射到类别空间，输出分类结果。

### 1.2 损失函数与优化器

- **交叉熵损失（Cross-Entropy Loss）**：适用于多分类任务，衡量预测概率分布与真实标签分布之间的差异。
- **Adam 优化器**：结合动量和自适应学习率的优化算法，能够自动调整每个参数的学习率。
- **StepLR 学习率调度器**：每 10 个 epoch 将学习率乘以 0.5，使模型在训练后期以更小的步长精细调整参数。

### 1.3 数据增强

通过对训练数据进行随机水平翻转和随机旋转（±15°），增加数据多样性，提高模型的泛化能力。

## 二、设计思路

### 2.1 整体架构

```
数据加载 → 数据增强 → CNN特征提取 → 分类输出 → 损失计算 → 参数更新
```

### 2.2 网络结构设计

采用 3 个卷积块 + 1 个全连接层的结构：

| 卷积块 | 输入通道 | 输出通道 | 卷积核 | 池化 | Dropout |
|--------|----------|----------|--------|------|---------|
| Block 1 | 3 | 32 | 3×3 | 2×2 MaxPool | 0.25 |
| Block 2 | 32 | 64 | 3×3 | 2×2 MaxPool | 0.25 |
| Block 3 | 64 | 128 | 3×3 | 2×2 MaxPool | 0.25 |

- 每个卷积块包含 2 个卷积层 + BatchNorm + ReLU
- 使用自适应平均池化（AdaptiveAvgPool2d）将特征图统一调整为 16×16
- 全连接层：128×16×16 → 256 → 5（类别数）

### 2.3 训练策略

1. **断点续训**：支持保存和加载检查点，避免训练中断导致进度丢失
2. **最佳模型保存**：每次测试准确率提升时保存最佳模型权重
3. **可视化监控**：训练完成后自动生成损失曲线和准确率曲线图
4. **详细评估**：训练结束后对测试集逐样本输出预测结果

### 2.4 数据集

- **训练集**：5 类中药材图像（百合、党参、枸杞、槐花、金银花），共约 900 张
- **测试集**：每类 2 张，共 10 张
- **图像尺寸**：统一调整为 128×128 像素
- **数据预处理**：归一化到 [-1, 1] 范围

## 三、关键代码

### 3.1 CNN 模型定义

```python
class ChineseHerbCNN(nn.Module):
    def __init__(self, num_classes=5):
        super(ChineseHerbCNN, self).__init__()
        self.conv_layers = nn.Sequential(
            nn.Conv2d(3, 32, kernel_size=3, padding=1),
            nn.BatchNorm2d(32),
            nn.ReLU(inplace=True),
            nn.Conv2d(32, 32, kernel_size=3, padding=1),
            nn.BatchNorm2d(32),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=2, stride=2),
            nn.Dropout2d(0.25),
            # ... Block 2 & Block 3 类似结构
        )
        self.pool = nn.AdaptiveAvgPool2d((16, 16))
        self.fc_layers = nn.Sequential(
            nn.Flatten(),
            nn.Linear(128 * 16 * 16, 256),
            nn.ReLU(inplace=True),
            nn.Dropout(0.5),
            nn.Linear(256, num_classes)
        )
    
    def forward(self, x):
        x = self.conv_layers(x)
        x = self.pool(x)
        x = self.fc_layers(x)
        return x
```

### 4.4 结果分析

#### 损失曲线分析

- **训练损失**：从初始的 4.95 快速下降到 1.0 以下（第 2 轮），之后缓慢下降至 0.74，表明模型在训练集上持续学习
- **测试损失**：从 1.18 下降到最低 0.46（第 25 轮），整体趋势与训练损失一致
- **损失差距**：训练损失与测试损失差距较小，说明模型未出现严重过拟合

#### 准确率曲线分析

- **训练准确率**：从 38.2% 稳步上升至 64.0%，呈现稳定增长趋势
- **测试准确率**：波动较大（40%~90%），在第 25 轮达到峰值 90%
- **波动原因**：测试集仅 10 张图像（每类 2 张），样本量小导致单次预测变化对准确率影响显著（±10%）

#### 关键观察

1. **最佳模型出现在第 25 轮**：此时测试准确率达到 90%，测试损失最低（0.46）
2. **后期波动**：第 25 轮后测试准确率有所下降，可能原因：
   - 测试集样本量过小，统计波动大
   - 模型在训练集上继续拟合，但泛化能力未同步提升
3. **学习率衰减效果**：第 10 轮和第 20 轮学习率衰减后，训练损失下降速度减缓，符合预期

## 五、实验结论

1. 基于 CNN 的中药材图像分类模型在 30 轮训练后达到 **90% 的最佳测试准确率**
2. 模型结构合理，包含 3 个卷积块和自适应池化层，能够有效提取图像特征
3. 数据增强（随机翻转、旋转）有助于提高模型泛化能力
4. 测试集样本量较小导致准确率波动较大，建议扩充测试集以获得更稳定的评估结果
5. 模型存在一定过拟合倾向（训练准确率 64% vs 最佳测试准确率 90% 的波动），可通过增加 Dropout 比例或数据增强强度进一步改善
