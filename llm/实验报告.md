## 二、实验原理

### 2.1 AI Agent基本概念

AI Agent是指能够感知环境、做出决策并执行行动的智能实体。一个完整的Agent通常包含以下核心组件：

| 组件 | 功能 | 本实验实现 |
|------|------|-----------|
| **推理/规划** | 分析问题、制定策略 | ReAct框架 |
| **记忆** | 存储和检索信息 | 短期记忆+长期记忆 |
| **工具** | 与外部环境交互 | 搜索工具+计算工具 |

### 2.2 ReAct推理框架

ReAct（Reasoning + Acting）是一种让大语言模型结合推理和行动的框架。其核心思想是：

```
Thought → Action → Observation → Thought → ... → Final Answer
```

- **Thought**: 分析当前情况，决定下一步行动
- **Action**: 执行工具调用或推理步骤
- **Observation**: 观察工具执行结果
- **Final Answer**: 给出最终结论

### 2.3 LangGraph框架

LangGraph是一个用于构建多Agent工作流的图结构框架。它通过节点（Node）和边（Edge）定义Agent之间的交互流程，支持条件路由和状态管理。

### 2.4 记忆机制原理

- **短期记忆**: 存储当前对话历史，用于上下文理解
- **长期记忆**: 持久化存储关键信息（论点、结论），支持跨会话复用

### 4.3 记忆机制实现

```python
class ShortTermMemory:
    """短期记忆 - 存储当前对话历史"""
    def __init__(self, max_messages: int = 20):
        self.max_messages = max_messages
        self.messages: List[Dict] = []
    
    def add_message(self, role: str, content: str):
        self.messages.append({
            "role": role, "content": content,
            "timestamp": datetime.now().isoformat()
        })
        if len(self.messages) > self.max_messages:
            self.messages = self.messages[-self.max_messages:]

class LongTermMemory:
    """长期记忆 - 持久化存储关键信息"""
    def __init__(self, storage_path: str):
        self.storage_path = storage_path
        self.memory: Dict = self._load_memory()
    
    def add_argument(self, side: str, argument: str):
        self.memory["arguments"].append({
            "side": side, "argument": argument,
            "timestamp": datetime.now().isoformat()
        })
        self._save_memory()
```

### 4.4 图结构构建

def create_debate_graph():
    workflow = StateGraph(DebateState)
    
    workflow.add_node("moderator", moderator_node)
    workflow.add_node("affirmative", affirmative_node)
    workflow.add_node("negative", negative_node)
    workflow.add_node("judge", judge_node)
    
    workflow.set_entry_point("moderator")
    workflow.add_edge("moderator", "affirmative")
    workflow.add_edge("affirmative", "negative")
    
    workflow.add_conditional_edges(
        "negative",
        route_after_negative,
        {"continue": "moderator", "judge": "judge"}
    )
    
    workflow.add_edge("judge", END)

### 6.4 存在问题与改进方向

**问题1：Ollama模型响应较慢**
- 现象：本地9b模型推理约需数分钟/轮，2b模型仍需较长时间
- 原因：本地模型推理耗时较长，受硬件性能限制
- 改进：可使用更小模型或接入云端API（如阿里云DashScope）

**问题2：工具调用未完全激活**
- 现象：搜索工具在当前环境下未能实时调用
- 原因：网络环境限制导致DuckDuckGo搜索无法正常工作
- 改进：在具备网络条件的环境下可完全激活搜索工具

**问题3：辩论未完成到评委评判**
- 现象：由于模型响应慢，用户中断了运行
- 原因：等待时间过长
- 改进：优化辩论轮次设置，减少每轮发言长度，或使用更快的模型

**问题4：部分空论点记录**
- 现象：记忆文件中存在部分空字符串论点
- 原因：模型返回空响应或网络超时
- 改进：增加错误处理和重试机制
