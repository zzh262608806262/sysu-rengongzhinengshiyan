## 1. 实验原理

### 1.1 人工神经网络介绍

神经网络采用了仿生学的思想，通过模拟生物神经网络的结构和功能来实现建模。神经网络由大量的神经元（Neuron）组成，每个神经元接收输入，对输入进行计算并产生输出。

### 1.2 单层感知机 (Perceptron)

M-P神经元模型参数需要事先设定好，为了能够自适应学习出所需要的参数，研究人员提出了单层感知机。

感知机的基本公式为：
```
y(x) = sign(wx + b)
```
其中sign为符号函数，当自变量为正数时取值为1，否则取值为0。

### 1.3 多层感知机 (MLP)

多层感知机（Multi-Layer Perceptron，简称MLP）包含三个层次：
- 一个输入层
- 一个或多个中间层（也叫隐藏层，hidden layer）
- 一个输出层

输入层与输出层的节点数是固定的，中间层则可以自由指定。MLP通常还会引入偏置单元b。

### 1.4 激活函数

常用激活函数：
- **Sigmoid**: 多用于多层神经网络(MLP)
- **ReLU**: 多用于深层神经网络(DNN)
- **Tanh**: 多用于深层神经网络(DNN)

### 1.5 损失函数

损失函数的作用是衡量网络表现是否良好，并为之后的网络参数优化提供指导。

分类任务常用损失函数：
- **均方误差 (MSE)**:
```
L = (1/n) * Σ(y_pred - y_true)²
```
- **交叉熵**: 用于分类任务

### 1.6 梯度下降

梯度是一个向量，表示某一函数在该点处的方向导数沿着该方向取得最大值。沿着梯度方向容易找到函数最大值，沿着梯度方向的反方向，容易找到函数最小值。

梯度下降的一般公式为：
```
θ = θ - α * ∇L(θ)
```
其中α是学习率，∇L(θ)是对θ的梯度。

### 4.2 MLP模型实现 (mlp_model.py)

```python
class MLP:
    def __init__(self, input_size, hidden_sizes, output_size=1, activation='relu'):
        """
        初始化MLP，使用He初始化权重
        """
        self.weights = []
        self.biases = []
        
        # 输入层 -> 隐藏层（He初始化）
        for hidden_size in hidden_sizes:
            std = np.sqrt(2.0 / prev_size)
            self.weights.append(np.random.randn(prev_size, hidden_size) * std)
            self.biases.append(np.zeros((1, hidden_size)))
            prev_size = hidden_size
        
        # 输出层
        self.weights.append(np.random.randn(prev_size, output_size) * 0.01)
        self.biases.append(np.zeros((1, output_size)))
```

**前向传播**:
```python
def forward(self, X):
    self.cache = {'a0': X}
    a = X
    
    # 隐藏层：线性变换 + ReLU激活
    for i in range(len(self.weights) - 1):
        z = np.dot(a, self.weights[i]) + self.biases[i]
        a = np.maximum(0, z)  # ReLU
        self.cache[f'z{i+1}'] = z
        self.cache[f'a{i+1}'] = a
    
    # 输出层：线性输出（回归任务不需要激活函数）
    z_out = np.dot(a, self.weights[-1]) + self.biases[-1]
    return z_out
```

**反向传播**:
```python
def backward(self, y, learning_rate, clip_threshold=1.0):
    m = y.shape[0]
    n_layers = len(self.weights)
    
    # 输出层误差 (MSE导数)
    dz_out = self.cache[f'a{n_layers}'] - y.reshape(-1, 1)
    dz_out = np.clip(dz_out, -clip_threshold, clip_threshold)  # 梯度裁剪
    
    # 反向传播
    for i in range(n_layers - 1, -1, -1):
        a_prev = self.cache[f'a{i}'] if i > 0 else self.cache['a0']
        
        # 计算梯度
        dW = np.dot(a_prev.T, dz_out) / m
        db = np.mean(dz_out, axis=0, keepdims=True)
        
        # 梯度裁剪
        dW = np.clip(dW, -clip_threshold, clip_threshold)
        db = np.clip(db, -clip_threshold, clip_threshold)
        
        # 更新参数
        self.weights[i] -= learning_rate * dW
        self.biases[i] -= learning_rate * db
        
        # 计算前一层的误差
        if i > 0:
            dz_prev = np.dot(dz_out, self.weights[i].T) * (self.cache[f'z{i}'] > 0)
            dz_prev = np.clip(dz_prev, -clip_threshold, clip_threshold)
            dz_out = dz_prev
```

### 4.3 训练流程 (train.py)

```python
def train(model, X_train, y_train, X_val=None, y_val=None,
          epochs=1000, learning_rate=0.01, batch_size=32, print_every=100):
    """
    小批量梯度下降训练
    """
    n_samples = X_train.shape[0]
    history = {'train_loss': [], 'val_loss': []}
    
    for epoch in range(epochs):
        # 打乱数据
        indices = np.random.permutation(n_samples)
        X_shuffled = X_train[indices]
        y_shuffled = y_train[indices]
        
        # 小批量训练
        for i in range(0, n_samples, batch_size):
            X_batch = X_shuffled[i:i+batch_size]
            y_batch = y_shuffled[i:i+batch_size]
            
            # 前向传播
            y_pred = model.forward(X_batch)
            
            # 反向传播
            model.backward(y_batch, learning_rate)
        
        # 记录损失
        history['train_loss'].append(mean_squared_error(y_train, model.predict(X_train)))
        if X_val is not None:
            history['val_loss'].append(mean_squared_error(y_val, model.predict(X_val)))
    
    return history
```
